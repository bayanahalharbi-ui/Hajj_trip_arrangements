# موقع ترتيبات ضيوف إمارة منطقة مكة المكرمة — نسخة مطابقة للتصميم المرجعي

---

## 🖼️ كيف تضيف الشعار الرسمي الصحيح

ما قدرت أنشئ الشعار الرسمي بنفسي (رمز حكومي رسمي)، لكن المكان جاهز بالكود ينتظر صورتك مباشرة. الخطوات:

1. جهّز صورة الشعار عندك (يفضل ملف **PNG بخلفية شفافة**، مربّع الأبعاد تقريبًا، مثل 300×300 بكسل).
2. سمّها بالضبط: **`logo.png`**
3. ارفعها داخل مجلد `assets/` عن طريق GitHub (زر **Add file → Upload files** داخل المجلد).
4. خلاص — الشعار بيظهر تلقائيًا في كل الصفحات (الصفحة الرئيسية، الجدول، تفاصيل اليوم، أوقات الصلاة) لأنها كلها تقرأ نفس الملف `assets/logo.png`.

> لو ما رفعت الصورة، الموقع يعرض دائرة منقّطة مكتوب فيها "ضع شعار الجهة هنا" بدل الشعار — علشان تعرف إذا نسيت الخطوة.

---

## ⚠️ ملاحظة أمان (نفس الملاحظة السابقة)

الملف الأصلي اللي أرسلته معلّم **"سرّي غير قابل للنشر"**. أي موقع على GitHub Pages يكون **عام بالرابط** حتى لو الملفات داخل مستودع خاص. إذا حبيت أضيف كلمة مرور بسيطة تظهر قبل الدخول، قلّي بأي وقت.

كذلك: **الأسماء وأرقام الجوالات الحقيقية ما ضفتها في الكود** — تركت حقول فاضية بالشكل `[الاسم هنا]` و`[رقم الجوال هنا]` داخل `data/home.txt`، تعبونها أنتم مباشرة.

---

## الخطوة ١: رفع الموقع على GitHub (مرة وحدة فقط)

1. أنشئ حساب على [github.com](https://github.com) إذا ما عندك.
2. **New repository** → اسم مثل `hajj-1447` → **Public** → **Create repository**.
3. من الصفحة اضغط **uploading an existing file** وارفع كل الملفات والمجلدات بهذا المشروع (حافظ على `assets/` و `data/` كما هي)، ولا تنسَ رفع `assets/logo.png` بعد تجهيزه.
4. **Settings → Pages** → Source: **Deploy from a branch** → الفرع `main` والمجلد `/ (root)` → **Save**.
5. بعد دقيقة أو دقيقتين يطلع رابط الموقع في نفس الصفحة (`https://username.github.io/hajj-1447/`).

---

## الخطوة ٢: كيف يعدّل الفريق المحتوى

نفس الطريقة في كل مكان: افتح الملف داخل GitHub → أيقونة القلم ✏️ (Edit) → عدّل → **Commit changes**. الموقع يتحدث تلقائيًا خلال دقيقة.

### أ) الصفحة الرئيسية (الاسم، السنة، جهات الاتصال)
افتح `data/home.txt`. كل قسم يبدأ بـ `### ` واسم القسم — عدّل النص تحت العنوان فقط، لا تلمس سطر `###` نفسه.

### ب) إضافة أو حذف فعاليات يوم معيّن (لتغيير العدد مثلاً من ٣ إلى ٩)
1. افتح `data/schedule/` واختر ملف اليوم (مثال: `arafah.csv` ليوم عرفة).
2. اضغط ✏️ — GitHub يعرضه كجدول تفاعلي (Table) زي Excel.
3. زر **+** بآخر صف لإضافة فعالية، وزر السلة 🗑 لحذف صف.
4. الأعمدة: `الوقت` (اتركه فاضي إذا ما تبي شارة وقت ملوّنة)، `التصنيف` (اختر واحدة من: `move` تحرك/باص، `gather` تجمع، `prayer` صلاة، `meal` وجبة، `stay` مبيت، `arrive` وصول — أو اتركه فاضي لأيقونة عامة)، `الفعالية` (نص العنوان)، `ملاحظات` (يظهر بلون أحمر تحت العنوان، مثل "التنسيق مع المراسم")، `اسم_الموقع` و `رابط_الموقع` (اختياري — يضيف أيقونة دبّوس قابلة للضغط).
5. **Commit changes**.

### ج) أوقات الصلاة
ملف واحد: `data/schedule/prayer-times.csv` — صف واحد لكل يوم، بنفس طريقة تعديل الجداول.

### د) تغيير لون يوم أو اسمه أو تاريخه
ملف `data/schedule/days.csv` يتحكم بكل شي عن كل يوم (الاسم، التاريخ، ولون اليوم المستخدم بكل صفحاته). عمود `لون` يقبل: `tarwiyah`، `arafah`، `nahr`، `tashreeq1`، `tashreeq2` (خمسة ألوان جاهزة بالتصميم).

## ملاحظات عامة
- لا تحتاج تلمس `assets/style.css` أو `assets/main.js` أو أي ملف `.html` — هذي التصميم الثابت فقط.
- لو انكسر شيء بالخطأ، افتح تبويب **History** لأي ملف بـ GitHub وارجعه لنسخة سابقة.
